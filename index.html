PROJECT 01 · REV A

Underwater ROV for Aquaculture Monitoring

Remotely Operated Vehicle based on Arduino UNO R3
Ce‑MEBSA Crocodic

A Robotics ROV integrated with an image‑processing‑based fish counting system to monitor floating net cages (KJA). Built to improve mobility and cut diving costs, while predicting fish count and average size for harvest planning — with an intuitive interface for reviewing underwater footage.

Arduino UNO R3 EasyEDA / PCB Fusion 360 3D Printing Image Processing
PROJECT 02 · R&D

LoRa Shock Monitoring & AED Device Benchmarking

Prototype benchmarking for Beomhoit / Beomho Teknologi Services
Beomhoit · Beomho

Benchmarking work for building anti‑theft and intrusion‑detection prototypes. Includes a SmartBox shock monitoring system using an ADXL345 accelerometer to detect physical disturbances — classifying each impact as Light, Medium, or Heavy and transmitting it wirelessly over LoRa 923 MHz to a real‑time web dashboard — as well as an AED Device prototype that detects door‑open events from accelerometer data processed on a Jetson Nano.

ADXL345 Jetson Nano LoRa 923MHz Flask PySerial SQLite
PROJECT 03 · R&D

3‑Model IoT Controller Prototypes

Environmental monitoring devices for a textile manufacturing factory
Textile Manufacturing Factory

Designed and built three ESP32C3‑based IoT controller models for factory environmental monitoring, each communicating over MQTT. Model 1 (SHT31 temperature/humidity + INA219 voltage sensor, battery‑powered), Model 2 (SPS30 dust sensor + SHT31, main power), and Model 3 (SPS30 dust sensor only, main power) — two showcase units built per model. Currently in R&D / prototype stage.

ESP32C3 SHT31 INA219 SPS30 MQTT
