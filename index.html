PROJECT 01 · REV A

Underwater ROV for Aquaculture Monitoring

Remotely Operated Vehicle based on Arduino UNO R3
Ce‑MEBSA Crocodic

A Robotics ROV integrated with an image‑processing‑based fish counting system to monitor floating net cages (KJA). Built to improve mobility and cut diving costs, while predicting fish count and average size for harvest planning — with an intuitive interface for reviewing underwater footage.

Arduino UNO R3 EasyEDA / PCB Fusion 360 3D Printing Image Processing
PROJECT 02 · REV A

LoRa Shock Monitoring System

Anti‑theft proof‑of‑concept for Beomhoit / Beomho Teknologi Services
Beomhoit · Beomho

A proof‑of‑concept shock monitoring system embedded inside a SmartBox as an anti‑theft measure. Uses an ADXL345 accelerometer to detect physical disturbances, classifying each impact as Light, Medium, or Heavy — transmitted wirelessly over LoRa 923 MHz and visualized on a real‑time web dashboard.

ADXL345 LoRa 923MHz Flask PySerial SQLite
